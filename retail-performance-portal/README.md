# 소매 · 도매 통합 실적관리 웹 포털

소매 담당 실무자를 위해 **판매현황 · 실적보고(채널별 + 주요대리점) · 사용자관리(티키타카 자동연동)** 3개 탭으로 재구성한 Next.js + Vercel 배포용 웹 프로젝트입니다.

## 주요 기능

1. **판매현황**
   - 도·소매 통합 KPI 카드 7종 (전체 개통, 010 신규, MNP, 기변, 중고신규, 중고MNP, 유선 초고속/IPTV)
   - 기간 기준 토글 (`실시간` / `일별` / `기간 조회` / `당월 누적`)
   - 채널 필터 (`전체` / `소매 전체` / `도매`), 매장명·판매유형·모델군·검색어 필터 및 개통 상세 내역 조회 + 엑셀 다운로드

2. **실적보고**
   - **채널별 실적 (도/소매 통합)**: 소매 17개 지정 매장 + 미등록 소매 + 도매 통합표, `바로픽업`/`초고속`/`IPTV` 인라인 수정, `모델군 관리`·`매장명 관리`, 카톡용 공지 텍스트 자동 생성 및 표 이미지 복사/저장
   - **주요대리점 실적**: 무선·유선 문자 통계 붙여넣기, 공동순위·1위 GAP 계산, `대교` 기준 13/15/17/20시 누적 추이표(날짜별 보존), 카톡용 요약 문구 및 이미지 미리보기/복사/저장

3. **사용자관리**
   - **티키연동**: T.Key-taka 계정 로그인 + SMS 6자리 문자 인증 UI, 자동연동 스케줄 설정(`09:00~21:00`), 수동 엑셀 업로드(`T판매관리`, `유선판매`), 실행 이력 로그
   - **사용자 · 권한 관리**: 본사코드 설정, 팀조직별 탭 권한 제어, 사용자 상태 관리

## Vercel 배포 방법

1. 압축을 해제한 폴더를 GitHub 저장소에 업로드합니다.
2. [Vercel](https://vercel.com/)에서 해당 저장소를 Import하여 배포합니다 (`Framework Preset: Next.js`).
3. Vercel 프로젝트 **Settings > Environment Variables**에 `.env.example`의 환경변수를 등록합니다.

## 티키타카(T.Key-taka) 실제 자동연동 연결 방법

- 이 프로젝트에는 `/api/tkey/auth`, `/api/tkey/sync`, `/api/cron/tkey-sync` API 라우트가 포함되어 있습니다.
- 실제 T.Key-taka 시스템은 사내 계정 및 SMS 인증 세션이 필요하므로, `src/app/api/tkey/auth/route.ts`와 `src/app/api/tkey/sync/route.ts`의 어댑터 함수(`connectRealTkeyServer`, `fetchTkeyExcelRows`)에 실제 T.Key-taka 엔드포인트 또는 사내 크롤러 게이트웨이 주소를 연결하면 자동연동이 활성화됩니다.
- 연동 전까지는 **사용자관리 > 티키연동 > 수동 파일 업로드**에서 `T판매관리`와 `유선판매` 엑셀을 올리면 즉시 전 화면에 반영됩니다.

## 중앙 DB (Supabase) 연동 설정 (접속 시 자동 로그인 상태 · 실적 공유)

1. [Supabase](https://supabase.com/)에서 무료 프로젝트를 생성합니다.
2. **SQL Editor**에서 이 프로젝트의 `supabase/schema.sql` 내용을 붙여넣고 실행합니다.
3. **Project Settings > API**에서 `Project URL`과 `service_role` 키를 복사해 Vercel 환경변수(`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`)에 등록합니다.
4. 이제 대표 1명이 한 번만 SMS 인증을 완료해 두면, 이후 어떤 PC/모바일에서 접속해도 `연동됨` 상태와 최신 실적이 자동으로 불러와집니다.
